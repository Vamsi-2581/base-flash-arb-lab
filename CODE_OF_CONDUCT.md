# Code of conduct

## The short version

Be decent. This is a small research project, not a debating arena.

## Expected behaviour

- Critique the measurement, not the person. "This sample is too small to support that
  claim" is welcome; "you don't know what you're doing" is not.
- Bring evidence. A disagreement about a number is settled by a block, a command or a
  citation, not by repetition.
- Accept a negative result. Most of this repository is one. Being wrong about a strategy
  is the normal outcome, not a failure of character.
- Respect scope. Issues that ask this project to become a profitable bot will be closed
  with a pointer to the findings.

## Unacceptable behaviour

- Harassment, insults, or discriminatory language of any kind.
- Publishing someone's private information without consent.
- Promoting strategies whose profit comes from harming other users — sandwiching,
  front-running retail flow, or fake volume.
- Posting private keys, seed phrases or API credentials anywhere in this repository,
  including issues and pull requests.
- Sustained disruption of discussions after being asked to stop.

## Scope

This applies to issues, pull requests, discussions, commit messages and any other space
where someone is representing this project.

## Enforcement

Report a problem to the maintainer through the contact details in [README.md](README.md).
Reports are handled privately. Responses may range from a request to stop, through
deleting a comment, to a permanent ban. There is no appeals committee; there is one
maintainer and a preference for a quiet repository.
